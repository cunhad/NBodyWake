I realized there may be an important methodological issue in the current MIL/attention implementation.

Right now, during validation/test, the network is not only receiving the input volume X, but also a subvolume prior (subvol_prior) derived from subvol_label.

The problem is that subvol_label is constructed using the known wake/no-wake signal difference:

wake_subvolume_signal - no_wake_subvolume_signal

So during evaluation, the model is effectively being told which subvolumes are more wake-like according to a statistic computed using ground-truth paired information.

This can create target leakage / optimistic evaluation, because in a real detection scenario we would only have the unknown volume itself, not the paired no-wake information.

Conceptually, the current evaluation is closer to:
“Here is the volume, and here is a hint about where the wake may be.”

instead of:
“Here is the volume; detect the wake from the data alone.”

I think the safest solution is:

during training: optionally keep the prior as supervision/guidance
during validation/test: replace the prior with a uniform prior (all subvolumes equally likely)

Then we can compare:

performance with informed prior
performance with uniform prior

If the performance remains strong with the uniform prior, the result becomes much more trustworthy and publishable.
